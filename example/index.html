System Overview & API Health

Quick status check of your local backend, database connectivity, and registered providers.

Server Health Check GET
Endpoint: /health

Checks server uptime, memory, and MongoDB connection state without credentials.

Provider Discovery GET
Endpoint: /api/v1/proxy/providers

Lists all 5 categories and the 10 registered demo providers with failover pairs.

Auth Routes Catalog GET
Endpoint: /api/v1/auth

Returns interactive documentation and definitions of all authentication endpoints.

User Registration

Register a new account. Dispatches a 6-digit verification code to the registered email address (printed to server console in dev mode).

Register Account POST /api/v1/auth/signup
Required fields: name, phone_no, email, password, terms_accepted

Email Verification & OTP

Verify your account using the 6-digit OTP code received in your email or printed in the backend terminal.

Verify Code POST /api/v1/auth/verify-otp
Activates account and returns access + refresh JWT tokens
Resend Verification Code POST /api/v1/auth/resend-otp
Dispatches a new code with refreshed 10-minute validity

User Login

Authenticate with your email and password. Automatically saves JWT tokens and dispatches a "Try to login" email alert.

Log In POST /api/v1/auth/login
Issues JWT tokens and saves to active session for subsequent requests

Password Recovery

Request a password reset code and set a new password safely.

Forgot Password POST /api/v1/auth/forgot-password
Generates a 15-minute recovery code
Reset Password POST /api/v1/auth/reset-password
Set new password with code

Profile & Session Management

Inspect the authenticated profile using the stored Bearer token, refresh expired tokens, or log out.

Current User Profile GET /api/v1/auth/me
Requires active Authorization: Bearer <token>
Refresh Access Token POST /api/v1/auth/refresh-token
Obtains new access token using saved refresh token
Log Out POST /api/v1/auth/logout
Clears active session tokens from tester state

Developer API Key Management

Full CRUD operations for managing developer API keys with automated email notifications.

Create API Key POST /api/v1/auth/create-api-key
Generates sk_live_... key (shown only once)
List API Keys GET /api/v1/auth/api-keys
Fetch all active keys for current user
Update / Revoke Key PATCH & DELETE
Manage existing key by ID

AI API Key Validation

Direct validation endpoint used by AI agents and microservices to verify an API key against `userId` and `email`.

Validate API Key POST /api/v1/auth/api-keys/validate
Validates keyHash, active status, expiration, and user ownership

OneAPI Projects & Encrypted Key Vault

Create developer projects, obtain project tokens (`oneapi_dev_token_xxx`), store third-party provider keys in the AES-256-GCM vault, and configure routing.

Create Project POST /api/v1/projects
Generates project token for OneAPI Gateway proxying
Store Key in Encrypted Vault POST /api/v1/projects/:id/vault
Encrypted at rest using AES-256-GCM
Category Routing Configuration PUT /api/v1/projects/:id/routing
Set Primary and Fallback provider pairs

OneAPI AI Proxy with Failover

Interacts with Google Gemini (Primary). If Gemini fails (e.g. rate limit 429 or timeout), it automatically fails over to Groq / Pollinations AI in the same request!

AI Chat Completion POST /api/v1/proxy/ai/chat
Requires OneAPI Project Token (Authorization: Bearer oneapi_dev_...)

OneAPI Music Proxy (Deezer ➔ iTunes Failover)

Search music tracks across Deezer API (Primary) with transparent Apple iTunes Search API (Fallback) from public-apis.

Search Music GET /api/v1/proxy/music/search
Unified track format with 30s playable audio previews

OneAPI Weather Proxy (Open-Meteo ➔ Weatherstack Failover)

Real-time weather data with automatic failover between Open-Meteo (Primary) and Weatherstack / wttr.in (Fallback).

Current Weather GET /api/v1/proxy/weather/current
Normalized temperature, humidity, condition, and wind speed

OneAPI News Proxy (HackerNews ➔ Spaceflight Failover)

Real-time news search unifying HackerNews Algolia (Primary) and Spaceflight News API (Fallback).

Search News GET /api/v1/proxy/news/search
Normalized articles, titles, sources, and publication dates

OneAPI Environment Proxy (OpenAQ ➔ Open-Meteo Air Failover)

Global air quality, PM2.5, PM10, and AQI indices with OpenAQ (Primary) and Open-Meteo Atmospheric Air (Fallback).

Air Quality Indices GET /api/v1/proxy/environment/air-quality
Normalized AQI status, PM2.5, and PM10 metrics
